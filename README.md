# IPilot KG — MVP

Налоговый помощник для небольших магазинов (ИП) в Кыргызстане:
профиль ИП → своя ставка → учёт выручки → черновик отчёта STI-091_10 → напоминания о сроках → ИИ-помощник.

## Публикация на Vercel

1. vercel.com → **Add New… → Project** → импортируйте этот репозиторий с GitHub.
2. Framework Preset: **Other**. Build Command и Output Directory не трогайте.
3. **Environment Variables** → добавьте `OPENROUTER_API_KEY` = ваш ключ OpenRouter
   (по желанию `OPENROUTER_MODEL`, по умолчанию `openrouter/auto`).
4. **Deploy** → получите ссылку `*.vercel.app`.

Ключ хранится только в переменных окружения Vercel и используется серверной функцией `api/ai.js`. В браузер и в репозиторий он не попадает.
Без ключа приложение тоже работает: расчёты, черновик и сроки, только без ИИ.

### Как обновлять после дедлайна

Меняете код → `git push` → Vercel сам публикует новую версию по той же ссылке.
Для больших изменений делайте отдельную ветку: Vercel даст предварительную ссылку для проверки.

## Локальный запуск (без Vercel)

```bash
cp .env.example .env   # впишите ключ
python server.py       # нужен только Python 3.9+
```
Откройте http://localhost:8000.

## Своя ставка и цикл оплаты

- **Своя ставка.** У каждого ИП можно указать личную ставку (наличные и безнал) в опросе или в профиле → «Ставка и цикл оплаты».
  Она заменяет табличную во всех расчётах, черновике и напоминаниях. Если она отличается от таблицы ГНС, приложение
  показывает для справки и табличную ставку. Для видов деятельности вне таблицы (швейное, сауна и т.п.) расчёт работает только со своей ставкой.
- **Цикл отчёта и оплаты** выбирает сам ИП: «Каждый месяц» или «Раз в квартал» (в опросе, на главной и в профиле).
  Приложение не определяет цикл по выручке и не спорит с выбором. Отсчёт дней, срок на главной, список напоминаний
  и календарь перестраиваются под выбранный цикл.

## Как ИИ участвует

1. **Чат-помощник.** Получает профиль ИП, готовый расчёт и 4 подходящих фрагмента из базы ГНС; отвечает со ссылками [1], [2].
2. **Разбор выручки словами**: «продал на 15 тыс, из них 5 тыс переводом» → наличные 10 000, безнал 5 000. Если ИИ недоступен, работает простой разбор без ИИ.
3. **Объяснение отчёта по шагам** для кабинета налогоплательщика, строго с цифрами из расчёта.

Ставки, суммы и сроки ИИ не придумывает: он получает их от `rules.js`.

## Модель

В `.env` стоит `OPENROUTER_MODEL=openrouter/auto` (OpenRouter выбирает модель сам).
Чтобы расходы были предсказуемыми, впишите конкретную модель со страницы openrouter.ai/models.
Проверьте до демо, что она хорошо отвечает на кыргызском.

## Демо-сценарий (совпадает со слайдом MVP)

1. Главная (пример «Айгуль, магазин одежды»): налог 5 000 сом, ставка 0,5%, срок, ячейки 050/051/052.
2. «Выручка» → написать «продал на 15 тыс, из них 5 тыс переводом» → «Разобрать» → «Добавить».
3. «Отчёт» → черновик STI-091_10 с жёлтыми ячейками → «ИИ: объясни мой отчёт по шагам».
4. «Помощник» → «Нужно ли мне сдавать ЕНД?» → ответ со ссылкой на документ ГНС.
5. Профиль → напоминания → «Добавить в Google Календарь».
6. Переключить на KG.

## Что проверить до защиты

- **Ставки после 22.08.2026.** Таблица взята со страницы ГНС «Единый налог». Ставку 5% для общепита в Бишкеке и Оше
  приложение помечает как требующую проверки. Позвоните в 116 и при необходимости поправьте `analyzeProfile` в `rules.js`.
- **Кыргызский перевод** интерфейса стоит вычитать носителю языка.
- **Ключ OpenRouter был отправлен в чат.** После хакатона создайте новый ключ на openrouter.ai и удалите старый.

Данные пользователя (профиль и выручка) хранятся только в его браузере (localStorage).
